# 200 個攝影關鍵字搜尋審查

基線建立：2026-09-17；內容審查接續至 2026-09-22。

**目前搜尋不能判定為「找出的都是該出現的影片」。** 已核實有零結果但存在教學、同義詞擴張過度、跨詞命中，以及只順帶提及卻排在教學之前的問題。時間點與來源正確，並不等於內容相關。

200 詞均已完成本輪規定範圍的內容審查，共判斷 **552 個已返回配對、260 個未顯示候選配對**。14 個零結果詞中，**13 個確認有可用來源**；「光繪」目前仍未確認。**48 個詞的前三部出現僅提及或不相關結果**，另有 5 個多義結果配對獨立列示。全體前三部共 540 個配對：468 可用、49 僅提及、14 不相關、4 待核、5 不同意圖。這是固定樣本的審查結果，不是全站準確率。

未顯示候選中有 209 個確認具學習價值，分布於 124 詞；其餘 33 僅提及、13 不相關、5 待核。這是值得納入候選池的來源清單，尤其廣義詞不應直接要求 209 個候選全部排到前三名。所有審查的覆蓋、段落 ID、排名、必讀原文旗標，以及搜尋與語料版本檢查均通過。

## 查了什麼

- [200 個關鍵字清單](KEYWORDS_200.md)：20 類各 10 詞，包括曝光、測光、對焦、構圖、光線、題材、鏡頭、後製與創作。固定清單後再查，不只挑成功的詞。
- [200 詞搜尋基線](BASELINE_200.md)：實際執行目前網站的搜尋函式，使用本機 1,058 支影片／60,712 段。產生 **6,383 個影片／關鍵字配對**，其中 **7,031 個逐字稿片段／關鍵字配對**的來源、原文與秒數均通過核對。數字包含同片被不同詞搜尋，不是獨立影片數。
- [逐詞內容審查總表](REVIEW_200.md)與[逐筆理由、影片及秒數](REVIEW_DETAILS.md)：由三個 Subagent 分批讀既有摘要、片段與必要完整原段落，主 Agent 核對紀錄並抽查重要案例。範圍是每詞前三部、最多兩部疑似偏離結果，以及少量未顯示候選；個別案例另補來源。

**不把有限內容抽查寫成全部 6,383 個結果已讀完或已通過。** 對全部結果完成的是來源與字詞核對；沒有全部正確答案的完整標註，因此不公布整體搜尋準確率／召回率。不同意圖、只提及與無法確認的結果分開記錄。未顯示的有用影片，也不表示一定要高於所有現有結果；廣詞需要排序與更多結果的取捨。

## 審查本身也要避免誤判

1. 曲線可以是構圖線條或後製曲線，降噪可以是影像或收音，遮光罩也有不同用途。網站只收到關鍵字，不知道我們把詞放在哪一類；這些列「不同意圖」，不能一律說成錯片。
2. 獨立候選不是標準答案。Photoshop 的 PS 候選可能是遊戲機，星空候選也可能是食物「仰望星空派」；已閱讀後排除，不能拿全部候選數當漏收數。
3. 否定或不推薦某方法仍可能是有效教學。判斷的是有沒有實質內容，不是有沒有支持關鍵字代表的方法。
4. 判定某片有用，與搜尋顯示的第一個片段是否有用，是兩件事。相關教學可能在同片其他段落；審查記錄會留下替代來源，不把整片誤刪。

## 後續修正順序

1. **先修明確漏收與錯配。** 補已確認的術語／同義表述；保留自動與手動、機型等較窄意圖。測光／側光只對已確認的特定詞組處理，避免把真正側光教學一起改壞。
2. **再改善前排與片段選擇。** 區分有內容的解說、純提問、規格列舉、宣傳及玩笑，讓既有教學來源更容易被看到。先用現有摘要與有來源的離線紀錄，保持線上搜尋不呼叫即時 AI。
3. **查清候選在哪一步遺失。** 現有索引每詞最多 48 個位置、每片每詞 2 個位置；搜尋另有 24 片摘要補召回及 80 筆候選上限。這些可能影響涵蓋，但不能光看到沒顯示就怪上限，也不宜只把結果數調大。先逐例追查，再決定索引與排序調整。
4. **沿用同一批 200 詞重測。** 保留本輪不變基線；修改後另存結果，比較已確認正例／反例及前排品質。仍需增加未參與調整的關鍵字作驗收，避免只為這 200 詞寫死規則。
